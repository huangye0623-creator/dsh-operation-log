## 多任务与多 AI 协作

### 怎么“商量”

智能体之间无法直接聊天，**商量 = 读写同一个文件**：

1. **开工前**：先读 `当前状态.md`（一页看板）+ `交接记录.md`（最近条目），知道现在在做什么、上一个人留了什么坑。
2. **收工前**：在 `交接记录.md` **最上面**加一条（不要追加到末尾）。
3. **每条格式固定**：目标 / 改动或产出（路径）/ 验证 / 回滚 / 下一步 / 详情链接。
4. **每条尽量 ≤15 行**；长日志、命令输出、大表格放项目文件夹或交付目录，这里只留结论和链接。
5. **滚动保留最近 4~10 条**；更早的移入 `交接归档/YYYY-MM.md`，并更新主文件里的「归档索引」。
6. **禁止“整读再整写”**：大文件读会截断；只用 `edit` 在顶部插入，或用脚本按行拼接。
7. **同一文件同一时刻只让一个会话写**；写完再通知对方。
8. 涉及历史/项目/交接时，**先路由再读**：跑记录路由脚本，只读命中段（如果启用了 `tools/records`）。

### 安全

- 不在 Profile 里 `pnpm add` 带 peer 依赖的核心包；
- 不改工作区/子目录的权限、完整性标签；
- 改配置前先备份，并在版本记录里登记。
